## aurchive 블로그
Aurchive는 개발 및 디자인 분야에서 지인들과 함께 경험한 내용을 공유하고자 만든 팀 블로그 개발 프로젝트입니다. 프론트엔드에서는 포스트 작성 및 관리에 중점을 두어 카테고리(스토리) 생성, 게시글 자동 저장 및 임시 저장 등의 기능을 구현했습니다. 백엔드에서는 사용자 인증, 게시글 CRUD, SSR과 SEO를 위한 동적 사이트맵 생성에 집중했습니다.
### 기술스택
- Firebase
- express
- React + Typescript
- Radix UI
- Emotion JS
- Tiptap
- react-helmet-async
